# Scryfall Analytics Exercise

## Why this datasource?
This project will use the 'Oracle Cards' file from [Scryfall's bulk data API](https://scryfall.com/docs/api/bulk-data). I chose this dataset because I enjoy Magic the Gathering and I'm expecting to be able to explore some fun and interesting questions about the cards and the game after ingesting the data, transforming it, and inserting it into SQLite.
